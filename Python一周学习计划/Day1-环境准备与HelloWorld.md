# Day 1：环境准备与 HelloWorld

**今日目标（约 2 小时）**

1. 学会打开 Mac 的"终端"
2. 检查并安装 Python
3. 运行人生第一行代码：`print("Hello, World!")`
4. 安装 VS Code，学会写 `.py` 文件并运行

---

## 1. 打开终端（约 10 分钟）

"终端"（Terminal）是 Mac 上一个用文字命令操作电脑的工具。以后运行 Python 代码经常会用到它。

两种打开方式，任选一种：

**方式一：聚焦搜索（推荐）**

1. 按键盘 `Command + 空格键`，屏幕中间会出现搜索框
2. 输入 `终端` 或 `Terminal`
3. 按回车键打开

**方式二：从访达进入**

1. 打开"访达"（Finder）
2. 左侧点"应用程序"
3. 打开"实用工具"文件夹
4. 双击"终端"

打开后你会看到一个可以输入文字的窗口，类似这样：

```
你的用户名@MacBook ~ %
```

那个 `%` 后面闪烁的光标，就是在等你输入命令。

## 2. 检查 Python 版本（约 10 分钟）

在终端里输入下面这行命令，然后按回车：

```
python3 --version
```

两种可能的结果：

- **显示版本号**（比如 `Python 3.12.5`）：说明电脑里已经有 Python，版本号 ≥ 3.8 就可以直接用，跳到第 3 节。
- **显示 `command not found`**（找不到命令）：说明需要安装 Python，继续往下看。

**安装 Python 的步骤：**

1. 用浏览器打开官网：https://www.python.org/downloads/
2. 点页面上的黄色大按钮 "Download Python 3.x.x"
3. 下载完成后双击打开下载的 `.pkg` 文件
4. 一路点"继续"→"同意"→"安装"，中间需要输入开机密码
5. 安装完成后，**关掉终端窗口重新打开**，再输入 `python3 --version` 确认能看到版本号

## 3. 第一行代码：Hello, World!（约 20 分钟）

在终端里输入 `python3` 然后回车：

```
python3
```

你会看到提示符变成了 `>>>`，这说明进入了 Python 的"交互式解释器"——你输入一行代码，它立刻执行一行。

现在输入：

```python
print("Hello, World!")
```

按回车，屏幕上会显示：

```
Hello, World!
```

恭喜！这是几乎所有程序员人生中的第一行代码。`print()` 的意思就是"把括号里的内容打印到屏幕上"。

再试两行，感受一下：

```python
print(1 + 2)
print("我正在学Python")
```

**退出解释器**：输入 `exit()` 回车，或者按 `Control + D`，提示符变回 `%` 就是退出了。

## 4. 安装 VS Code（约 30 分钟）

在终端里一行一行敲代码不方便，正式写代码我们用 **VS Code**。

**下载安装：**

1. 打开官网：https://code.visualstudio.com/
2. 点 "Download for Mac" 下载
3. 下载得到一个 `.zip` 文件，双击解压出 "Visual Studio Code.app"
4. 把它拖进"应用程序"文件夹
5. 第一次打开如果提示"是否打开来自互联网的应用"，点"打开"

**切换中文界面：**

1. 打开 VS Code，点左侧边栏最下面的方块图标（扩展）
2. 搜索框输入 `Chinese`，找到 "Chinese (Simplified) Language Pack"，点 "Install"
3. 安装完右下角会提示重启，点 "Restart" 就变成中文了

**安装 Python 扩展：**

1. 还是在扩展面板，搜索 `Python`
2. 找到微软官方发布的 "Python"（发布者显示 Microsoft），点"安装"
3. 装好后 VS Code 就能识别 Python 代码，还能一键运行

**VS Code 基础操作，先记住这四个：**

| 操作 | 怎么做 |
|------|--------|
| 新建文件 | 菜单"文件"→"新建文本文件"，或 `Command + N` |
| 保存文件 | `Command + S`，保存时文件名以 `.py` 结尾 |
| 打开文件夹 | 菜单"文件"→"打开文件夹"，以后代码都放这个文件夹里 |
| 运行代码 | 打开 `.py` 文件后，点右上角的三角形 ▶ 按钮 |

## 5. 用 VS Code 写第一个程序（约 30 分钟）

1. 在"文稿"里新建一个文件夹，命名为 `python学习`
2. 打开 VS Code，菜单"文件"→"打开文件夹"，选中刚才的 `python学习`
3. `Command + N` 新建文件，马上 `Command + S` 保存为 `hello.py`
4. 在文件里输入：

```python
print("Hello, World!")
```

5. 点右上角 ▶ 运行按钮（第一次会让选择运行方式，选 "Python 文件"）
6. 下方会弹出终端面板，显示运行结果：

```
Hello, World!
```

以后每天的代码都这样：在 VS Code 里写好、保存、点 ▶ 运行。

## 今日小结

- 终端：用文字命令操作电脑的工具，`Command + 空格` 搜"终端"就能打开
- `python3 --version`：检查 Python 版本
- `print()`：把内容打印到屏幕
- VS Code：我们以后写代码的地方，记住 `Command + S` 保存、▶ 运行

## 如果卡住了怎么办

| 症状 | 可能原因和解决办法 |
|------|------|
| 终端输入 `python3` 提示 command not found | Python 没装好，或者装完没重开终端窗口。重开终端再试；还不行就重新走一遍安装步骤 |
| VS Code 点 ▶ 没反应 | 确认文件保存了（文件名旁没有白点），且文件名以 `.py` 结尾；确认装了 Python 扩展 |
| 中文打印出来是乱码或报错 | 检查 `print()` 用的是英文括号 `()` 和英文引号 `""`，不要用中文的（）和"" |
| 报错信息看不懂 | 先逐字检查自己敲的代码和教程里的是否完全一致，90% 的新手报错都是拼写问题 |
