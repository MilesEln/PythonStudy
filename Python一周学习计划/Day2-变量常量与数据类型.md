## 1. 变量：贴了标签的盒子（约 25 分钟）

变量可以理解成一个**贴了标签的盒子**：标签是变量名，盒子里装的是数据。用 `=` 把数据"放进"变量：

```python
name = "小明"
age = 18
height = 1.75
```

读法：`name = "小明"` 表示"把 '小明' 这个文字放进名叫 name 的盒子里"。

放进盒子之后，就可以通过标签随时取出来用：

```python
name = "小明"
age = 18
print(name)
print(age)
```

运行结果：

```
小明
18
```

变量里的内容可以随时换掉（所以叫"变"量）：

```python
age = 18
age = 19
print(age)
```

运行结果是 `19`，盒子里的旧内容被新内容覆盖了。

**变量命名规则（必须遵守）：**

- 只能由字母、数字、下划线组成
- 不能以数字开头：`1name` 错误，`name1` 正确
- 不能使用 Python 的保留字（比如 `print`、`if` 不能当变量名）
- 区分大小写：`age` 和 `Age` 是两个不同的变量

**命名习惯（不是强制，但大家都这么写）：** 用小写字母，多个单词用下划线连接，比如 `my_name`、`total_score`。名字要取得有意义，`score` 比 `s` 好。

## 2. 常量（约 10 分钟）

常量是"不应该被改变"的值，比如圆周率、一周的天数。Python 没有强制锁定常量的功能，但大家约定：**常量名全部大写**，看到全大写的名字就自觉不去改它。

```python
PI = 3.14159
DAYS_PER_WEEK = 7

print(PI * 2)
```

运行结果：`6.28318`

## 3. 四种基本数据类型（约 30 分钟）

盒子里的东西有不同种类，最常用的四种：

| 类型 | 名字 | 例子 | 说明 |
|------|------|------|------|
| 整数 | int | `18`、`-5`、`0` | 不带小数点的数 |
| 小数（浮点数） | float | `1.75`、`3.14` | 带小数点的数 |
| 字符串 | str | `"小明"`、`"Hello"` | 文字，必须放在引号里 |
| 布尔值 | bool | `True`、`False` | 只有"真"和"假"两个值，首字母大写 |

**用 `type()` 查看数据的类型：**

```python
name = "小明"
age = 18
height = 1.75
is_student = True

print(type(name))        # <class 'str'>
print(type(age))         # <class 'int'>
print(type(height))      # <class 'float'>
print(type(is_student))  # <class 'bool'>
```

**注意一个新手最常踩的坑**：引号会改变类型。

```python
a = 18      # 这是整数 int
b = "18"    # 这是字符串 str，只是"长得像数字的文字"
```

## 4. 类型转换（约 20 分钟）

不同类型的数据有时需要互相转换，常用三个函数：

- `int()`：转成整数
- `float()`：转成小数
- `str()`：转成字符串

```python
s = "18"
n = int(s)       # 把字符串 "18" 转成整数 18
print(n + 2)     # 20，可以正常做数学运算了

age = 18
text = str(age)  # 把整数转成字符串
print(type(text))  # <class 'str'>

pi = float("3.14")
print(pi * 2)    # 6.28
```

## 5. 字符串拼接与 f-string（约 20 分钟）

想把文字和变量组合在一起打印，有两种方式。

**方式一：用 `+` 拼接（只能拼字符串，数字要先转换）**

```python
name = "小明"
age = 18
print("我叫" + name + "，今年" + str(age) + "岁")
```

**方式二：f-string（推荐，简单好用）**

在引号前加一个 `f`，字符串里用 `{}` 把变量包起来，Python 会自动把变量值填进去，**不用手动转换类型**：

```python
name = "小明"
age = 18
height = 1.75
print(f"我叫{name}，今年{age}岁，身高{height}米")
```

运行结果：

```
我叫小明，今年18岁，身高1.75米
```

`{}` 里甚至可以直接写计算：

```python
age = 18
print(f"明年我就{age + 1}岁了")
```

运行结果：`明年我就19岁了`

## 今日小结

- 变量是贴了标签的盒子，`=` 是"放入"；常量约定全大写命名
- 四种基本类型：int（整数）、float（小数）、str（文字）、bool（真假）
- `type()` 看类型；`int()`、`float()`、`str()` 做转换
- f-string：`f"我叫{name}"`，花括号里放变量

## 如果卡住了怎么办

| 症状 | 可能原因和解决办法 |
|------|------|
| `SyntaxError: invalid syntax` | 检查变量名是不是以数字开头了，或字符串的引号是否成对出现 |
| `NameError: name 'xxx' is not defined` | 变量名拼错了，或在使用前没有先赋值。变量必须先"装进盒子"才能用 |
| `TypeError: can only concatenate str...` | 用 `+` 拼接时混进了数字。改用 f-string，或用 `str()` 先转换 |
| 布尔值报错 | `True` / `False` 首字母必须大写，且不要加引号（加了引号就变成字符串了） |
