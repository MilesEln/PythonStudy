## 1. if 语句：让程序学会"看情况"（约 25 分钟）

生活里的逻辑："**如果**下雨了，**就**带伞。" Python 里对应的就是 `if`：

```python
age = 18

if age >= 18:
    print("你已成年")
```

运行结果：`你已成年`

两个必须注意的格式细节：

1. `if` 条件后面有一个**英文冒号 `:`**
2. 冒号下面的代码要**缩进 4 个空格**（在 VS Code 里按一下 Tab 键就行）

**缩进是 Python 表达"归属关系"的方式**：缩进的行属于这个 if，条件成立才执行；不缩进的行不属于它，无论条件是否成立都会执行：

```python
age = 16

if age >= 18:
    print("你已成年")      # 缩进：条件成立才执行
print("程序结束")           # 不缩进：总会执行
```

运行结果只有：`程序结束`

## 2. if...else：二选一（约 15 分钟）

"如果下雨就带伞，**否则**就戴墨镜。"

```python
age = 16

if age >= 18:
    print("你已成年")
else:
    print("你还未成年")
```

运行结果：`你还未成年`

注意 `else` 后面也有冒号，它下面缩进的代码是"条件不成立时"执行的。

## 3. elif：多种情况（约 25 分钟）

情况不止两种时，用 `elif`（else if 的缩写）依次判断。**Python 从上往下检查，遇到第一个成立的条件就执行对应的代码，然后跳过后面所有分支**：

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

运行结果：`良好`

执行过程：先看 `85 >= 90`？不成立；再看 `85 >= 80`？成立，打印"良好"，后面的 `elif` 和 `else` 直接跳过。

`elif` 可以有任意多个，`else` 是"以上都不成立时"的兜底，可以省略。

## 4. 组合条件（约 15 分钟）

判断条件里可以用昨天学的比较和逻辑运算符：

```python
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("可以入场")
else:
    print("不能入场")
```

```python
day = "周六"

if day == "周六" or day == "周日":
    print("今天是周末！")
```

## 5. 嵌套判断（了解即可，约 10 分钟）

if 里面还可以再写 if，注意每一层都要再缩进一级：

```python
age = 20
has_ticket = True

if age >= 18:
    if has_ticket:
        print("可以入场")
    else:
        print("请先买票")
else:
    print("未满18岁不能入场")
```

嵌套层数多了会很难读，初学阶段最多嵌套两层。很多情况可以用 `and` / `or` 拍平成一层。

## 今日小结

- `if 条件:` 成立才执行；`else:` 兜底；`elif` 处理多种情况，从上到下匹配到就停
- **冒号和缩进（4 个空格）一个都不能少**，缩进错了程序逻辑就错了
- 判断相等用 `==`，不是 `=`
- 条件可以用 `and` / `or` / `not` 组合

## 如果卡住了怎么办

| 症状 | 可能原因和解决办法 |
|------|------|
| `SyntaxError: invalid syntax` 指向 if 那行 | 行尾忘写冒号 `:`，或把 `==` 写成了 `=` |
| `IndentationError` | 缩进出问题。检查是否统一用 Tab（或统一 4 空格），不要 Tab 和空格混用；VS Code 默认按 Tab 会自动转成 4 空格 |
| 条件明明成立却没执行 | 检查缩进——执行的代码有没有缩进到 if 里面；再检查条件本身，比如把字符串和数字比较（`input()` 忘转 `int()`） |
| elif 的判断结果和预期不一样 | 检查条件顺序。Python 从上往下匹配，范围大的条件写在上面会"拦截"后面的分支 |
