## 1. 列表 list：一排有顺序的格子（约 30 分钟）

一个变量只能装一个值，列表可以装**一组值**，像一排编了号的格子：

```python
fruits = ["苹果", "香蕉", "橙子", "葡萄"]
```

**取元素：用索引（格子编号），从 0 开始数**

```python
fruits = ["苹果", "香蕉", "橙子", "葡萄"]

print(fruits[0])   # 苹果（第1个的编号是0！）
print(fruits[2])   # 橙子
print(fruits[-1])  # 葡萄（负数从后往前数，-1是最后一个）
```

**切片：取其中一段**

```python
fruits = ["苹果", "香蕉", "橙子", "葡萄"]

print(fruits[1:3])   # ['香蕉', '橙子']（从1号到3号之前，和range一样不含结尾）
print(fruits[:2])    # ['苹果', '香蕉']（开头可以省略）
```

**长度和遍历**

```python
fruits = ["苹果", "香蕉", "橙子", "葡萄"]

print(len(fruits))        # 4，len() 得到列表里有几个元素

for fruit in fruits:      # 挨个取出每个元素
    print(f"我想吃{fruit}")
```

## 2. 列表的增删改（约 25 分钟）

```python
fruits = ["苹果", "香蕉", "橙子"]

# 改：通过索引直接赋值
fruits[1] = "西瓜"
print(fruits)   # ['苹果', '西瓜', '橙子']

# 增：append 在末尾追加
fruits.append("葡萄")
print(fruits)   # ['苹果', '西瓜', '橙子', '葡萄']

# 删：remove 按内容删除
fruits.remove("西瓜")
print(fruits)   # ['苹果', '橙子', '葡萄']

# 查：in 判断元素是否存在
if "苹果" in fruits:
    print("列表里有苹果")
```

**小例子：存放并统计成绩**

```python
scores = [85, 92, 78, 90, 88]

print(f"共{len(scores)}门课")
print(f"总分：{sum(scores)}")
print(f"平均分：{sum(scores) / len(scores)}")
print(f"最高分：{max(scores)}")
```

运行结果：

```
共5门课
总分：433
平均分：86.6
最高分：92
```

## 3. 字典 dict：像通讯录一样存数据（约 30 分钟）

列表靠"编号"找数据，字典靠"名字"找数据——就像通讯录：查"妈妈"就能找到她的电话。名字叫**键（key）**，对应的内容叫**值（value）**。

```python
# 创建字典：{键: 值, 键: 值}
phone_book = {
    "妈妈": "13800000001",
    "爸爸": "13800000002",
    "姐姐": "13800000003"
}

# 查：用键取值
print(phone_book["妈妈"])   # 13800000001

# 增 / 改：直接对键赋值（键不存在就是新增，已存在就是修改）
phone_book["哥哥"] = "13800000004"
phone_book["妈妈"] = "13900000001"

# 删
del phone_book["姐姐"]

# 查键是否存在
if "妈妈" in phone_book:
    print("有妈妈的电话")
```

**遍历字典**

```python
phone_book = {"妈妈": "13800000001", "爸爸": "13800000002"}

for name, number in phone_book.items():
    print(f"{name}的电话是{number}")
```

运行结果：

```
妈妈的电话是13800000001
爸爸的电话是13800000002
```

**字典的值可以是任何类型**，比如用一个字典描述一个人：

```python
me = {
    "name": "小明",
    "age": 18,
    "hobbies": ["篮球", "音乐"]   # 值也可以是列表
}
print(f"{me['name']}今年{me['age']}岁，爱好是{me['hobbies'][0]}")
```

## 今日小结

- 列表 `[]`：一组有顺序的数据，索引从 0 开始；`len()` 长度、`append()` 追加、`remove()` 删除、`in` 查存在、`for` 遍历
- 切片 `列表[开始:结束]`，不含结束位置
- 字典 `{}`：键值对，像通讯录；`字典[键]` 取值/赋值、`del` 删除、`in` 查键、`for k, v in 字典.items()` 遍历

## 如果卡住了怎么办

| 症状 | 可能原因和解决办法 |
|------|------|
| `IndexError: list index out of range` | 索引越界。3 个元素的列表合法索引是 0、1、2，没有 3 |
| `KeyError: 'xxx'` | 字典里不存在这个键。取之前先用 `if 键 in 字典:` 判断 |
| `ValueError: ... not in list` | `remove()` 删除的内容不在列表里 |
| 打印列表/字典出来格式和预期不同 | 直接 `print(列表)` 打印的是原始结构（带方括号/花括号），想逐行漂亮打印请用 for 循环 |
