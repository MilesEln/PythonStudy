## 1. 函数是什么（约 20 分钟）

函数像一份**食谱**：写好一次"怎么做"，以后想用的时候喊它的名字就行，不用重写一遍。

其实我们天天在用函数：`print()`、`input()`、`len()` 都是 Python 写好的函数。今天学自己写：

```python
def say_hello():
    print("你好！")
    print("欢迎学Python")
```

- `def` 是"定义"的意思，后面跟函数名和括号，行尾有冒号
- 函数体缩进 4 个空格（老朋友了）
- 定义只是"写好食谱"，**要调用才会执行**：

```python
def say_hello():
    print("你好！")
    print("欢迎学Python")

say_hello()   # 调用，打印两行
say_hello()   # 再调用一次，又打印两行
```

## 2. 参数：让函数接收外部信息（约 20 分钟）

食谱可以写"放两勺盐"，也可以写"放 x 勺盐"——x 由做菜的人决定。括号里的**参数**就是这个 x：

```python
def greet(name):
    print(f"你好，{name}！")

greet("小明")   # 你好，小明！
greet("小红")   # 你好，小红！
```

参数可以有多个：

```python
def add(a, b):
    print(f"{a} + {b} = {a + b}")

add(3, 5)    # 3 + 5 = 8
add(10, 20)  # 10 + 20 = 30
```

## 3. 返回值：让函数给出结果（约 25 分钟）

上面的函数只是"打印"结果，更常用的是让函数**把结果还给我们**，用 `return`：

```python
def add(a, b):
    return a + b

result = add(3, 5)   # 用变量接住返回的结果
print(result)        # 8
print(add(10, 20))   # 30，返回值可以直接用
```

`print` 和 `return` 的区别（新手最容易混）：

- `print`：把内容**显示给人看**，看完就没了
- `return`：把结果**交还给程序**，可以存进变量、继续参与计算

再看一个完整例子，把 Day 4 的成绩判断改造成函数：

```python
def get_level(score):
    if score >= 90:
        return "优秀"
    elif score >= 80:
        return "良好"
    elif score >= 60:
        return "及格"
    else:
        return "不及格"

s = float(input("请输入分数："))
level = get_level(s)
print(f"你的等级是：{level}")
```

函数一旦执行到 `return` 就立刻结束，所以每个分支 return 之后，后面的代码不会再执行。

## 如果卡住了怎么办

| 症状 | 可能原因和解决办法 |
|------|------|
| 调用函数后没有任何输出 | 函数体里只有 `return` 没有 `print`——返回值被丢掉了。用变量接住再打印，或直接 `print(函数(...))` |
| 函数里的代码完全不执行 | 只定义没调用。`def` 只是写好食谱，要写上 `函数名()` 才会"做菜" |
| `TypeError: ... takes 2 arguments but 1 was given` | 调用时传的参数个数和定义时不一致，数一数括号里的值 |
| 项目里改了一个功能，另一个功能坏了 | 正常，这就是真实编程。从头捋一遍数据怎么流动的：存进列表的是什么结构，取出来的时候按什么取的 |
