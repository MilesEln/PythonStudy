# Python 一周零基础学习计划 · 总览

这份计划适合**完全没有编程基础**的同学。每天大约 **2 小时**，跟着做就行，不需要提前懂任何代码知识。

| Day 2 | 变量、常量与基本数据类型 | `Day2-变量常量与数据类型.md` |

| Day 7 | 函数 + 综合小项目 | `Day7-函数与综合项目.md` |

## 怎么用这份计划

1. 按顺序从 Day 1 开始，每天打开对应的文件。
2. 看到代码不要只读——**亲手敲一遍**，再运行看看结果。
3. 每天的"动手练习"尽量独立完成，做不出来再回头看讲解。
4. 练习的参考答案放在 `answers/` 文件夹里，**先自己写，做完再对照**。答案里有注释解释每一行在做什么。
5. 每天结尾有"如果卡住了怎么办"，遇到问题先看那一节。

## IDE 推荐：Visual Studio Code

写代码推荐用 **Visual Studio Code（简称 VS Code）**，理由很简单：

- 完全免费，Mac 上运行流畅
- 可以切换成中文界面，对新手友好
- 代码自动上色（高亮）、自动补全，少犯拼写错误
- 装上 Python 扩展后，点一个按钮就能运行代码

> VS Code 的下载、安装和使用方法在 **Day 1** 里有详细步骤，第一天照做即可。

## 学习前的小提醒

- **报错是常态**，不是你不适合编程。程序员每天也在看报错，看懂报错信息就赢了一半。
- 每天 2 小时可以拆成两段，每段 1 小时，中间休息一下。
- 如果某天内容没消化完，宁可多花一天，也不要赶进度。
